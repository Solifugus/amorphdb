# AmorphDB Book Design

Name: "Learning Modern Business Language (MBL)"

The focus should be learning to build productive things in AmorphDB and therefore how to do things and not technology behind it.
This book should be practical.
The audience is a typical business manager or knowledge worker with average computer skills.
Generally, we don't want to provide prerequisites first but want to start with examples then explain how they work.
General tactic: Show the result, then how you get there.
